# 거점 장비 현황

지사·영업소·터널관리동 상세의 첫 항목은 CCTV 표입니다. 표에는 설치 위치, 카메라 종류, IP가 표시되고, 기타 장비는 그 아래에 표시됩니다. 빈 항목은 미기재로 표시합니다. 카메라 운영PC, NVR, 환경감시 장비는 CCTV 표에 포함하지 않습니다.

## 대장 가져오기

거점 상세 또는 **인프라 데이터팩 관리**에서 **자산관리대장 불러오기**를 선택하고, 대장에서 추출한 JSON을 고릅니다. 가져온 파일은 이 브라우저에서만 읽으며, 다시 열 때 사용할 수 있도록 브라우저 저장소에 암호화해 보관합니다. 다른 기기나 브라우저에서는 그 기기에서 한 번 불러옵니다. 기존 데이터팩과 지도 좌표는 변경하지 않습니다.

### 파일 갱신

Python과 openpyxl이 있는 환경에서 실행합니다. 출력 파일은 저장소 밖에 보관합니다.

```powershell
python scripts/extract-office-inventory.py "C:/Users/DBCS/Desktop/자산관리대장.xlsx" "C:/Users/DBCS/Desktop/GIS-자산관리대장-로컬.json"
```

`자산관리대장_자가통신망` 시트의 설치 위치, 시스템명, 장비명, 제조업체, 기기번호, IP, 원본 행 번호를 사용합니다. 동서울·경기광주 관내 거점과 앱에 등록된 수원신갈영업소를 연결합니다. 수원신갈영업소는 입구와 출구를 설치 위치에서 구분합니다. 광암터널은 연번이 없는 장비 행도 위치와 시스템명이 기재되어 있으면 포함합니다. 원본 엑셀과 생성한 JSON은 공개 저장소에 커밋하지 않습니다.
