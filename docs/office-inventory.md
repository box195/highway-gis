# 거점 장비 현황

지사·영업소·터널관리동 상세의 첫 항목은 CCTV 표입니다. 표에는 설치 위치, 카메라 종류, IP가 표시되고, 기타 장비는 그 아래에 표시됩니다. 빈 항목은 미기재로 표시합니다. 카메라 운영PC, NVR, 환경감시 장비는 CCTV 표에 포함하지 않습니다.

## 대장 반영 방식

거점 장비는 배포된 지사 데이터팩의 거점 기록에 포함됩니다. 앱을 열면 같은 대장을 바로 표시합니다. 대장에 포함된 장비 IP는 배포 앱에서 조회할 수 있습니다.

설치위치 셀에 거점 접두어가 있으면 거점 구분에 우선 사용합니다. 예를 들어 지사가 경기광주지사이고 설치위치가 `하남영_정문`이면, 하남영업소의 `정문` 장비로 표시합니다. 접두어 없는 동서울·경기광주 행은 지사 장비로 분류합니다.

### 대장 갱신

Python, openpyxl 및 Node.js가 있는 환경에서 실행합니다. 중간 JSON은 저장소 밖에 보관합니다.

```powershell
python scripts/extract-office-inventory.py "C:/Users/DBCS/Desktop/자산관리대장.xlsx" "C:/Users/DBCS/Desktop/GIS-자산관리대장-로컬.json"
node scripts/update-office-inventory.mjs "C:/Users/DBCS/Desktop/GIS-자산관리대장-로컬.json"
```

`자산관리대장_자가통신망` 시트의 설치 위치, 시스템명, 장비명, 제조업체, 기기번호, IP, 원본 행 번호를 사용합니다. 동서울·경기광주 관내 거점과 앱에 등록된 수원신갈영업소를 연결합니다. 수원신갈영업소는 입구와 출구를 설치 위치에서 구분합니다. 광암터널은 연번이 없는 장비 행도 위치와 시스템명이 기재되어 있으면 포함합니다. 새 데이터팩 배포 시 `index.html`의 `master_data.js` 버전도 갱신합니다.
