# 한국도로공사 ITS 통합 현황 시스템 (Highway GIS Client Viewer)

본 시스템은 한국도로공사 관내 고속도로 통신관로, 광케이블망, 맨홀/수공 및 ITS 현장 설비(CCTV, VDS, VMS, C-ITS)의 위치와 점검 일정을 시각화하는 순수 **클라이언트 사이드 웹 현황 지도 앱**입니다.

## 🔒 보안 및 로컬 데이터 구동 방식
- **서버 독립형 무저장소 아키텍처**: GitHub Pages 서버에는 어떠한 시설물 데이터나 좌표가 업로드되지 않으며, 순수 웹 뷰어 UI 엔진만 구동됩니다.
- **클라이언트 전용 로컬 암호화 저장소 (IndexedDB + Web Crypto AES-256)**:
  - 사용자가 업로드한 데이터팩(`.json`)은 브라우저 전용 로컬 샌드박스(IndexedDB)에 **AES-GCM 256비트 암호화**되어 보관됩니다.
  - 다음 접속 시 브라우저 내부에서 자동 복호화되어 매번 파일을 올릴 필요 없이 즉시 현황 지도가 로드됩니다.
- **다중 지사 통합 현황 지원**: 동서울지사, 경기광주지사 등 복수의 지사 데이터팩을 로컬에 등록하여 개별 지사 현황 및 전체 지사 통합 현황을 자유롭게 전환할 수 있습니다.
