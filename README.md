# 고속도로 지하 시설물 및 통신 인프라 관제 지도 시스템
(한국도로공사 수도권제1순환선 동서울지사 관내)

본 프로젝트는 고속도로 지하 통신관로, 맨홀, 광케이블 및 ITS/통신 장비(CCTV, VDS, VMS, C-ITS, 전주 등)를 실시간으로 시각화·탐색하고, 신규 엑셀/CSV 데이터를 동적으로 업로드 및 좌표 변환할 수 있는 **인터랙티브 GIS 관제 웹 애플리케이션**입니다.

---

## 🌟 주요 기능

1. **데이터 융합 & 정밀 시각화**
   - **맨홀 (120개소)**: 접속맨홀(녹색), 통과맨홀(황색), 인공/수공 구분 마커 및 클릭 시 상세 정보창
   - **통신관로 (120개 구간)**: 도로, 교량, 터널별 매설 형태, 외관 규격(PVC 100/150mm, COD 122mm, 스틸배관 등), 내관 규격(28mm 3조), 자가망 사용 현황
   - **광케이블 (15개 주요 구간)**: 판교 ~ 퇴계원 & 학의 ~ 평촌 간선 케이블, 코어 수(30C ~ 96C), 증설 차수
   - **ITS/통신 연계 장비 (118개소)**: CCTV, VDS(차량검지기), VMS(전광판), C-ITS(RSU/IDS), 비상전화 고유 아이콘 레이어
   - **전주 (7개소)**: 7m IP주 및 조가선 유무 정보

2. **레이어 제어 & 실시간 스마트 검색**
   - 시설물 유형별(맨홀, 관로, 케이블, CCTV, VDS, VMS, C-ITS, 전주) 독립 On/Off 토글
   - 구간별 필터 (판교-성남, 하남-상일, 강일-토평, 토평-남양주, 구리-퇴계원, 청계-학의, 학의-평촌 등)
   - 상/하행 방향별 필터 (상행선 판교방향 / 하행선 일산·퇴계원방향 / 전체)
   - 실시간 통합 검색: 시설물 ID(`M-1001-...`), 맨홀 번호(`2M`), 이정(`0.21km`), 장비명(`VDS-101-1`, `IDS-13`), IP 검색 및 자동 완성 이동(FlyTo)

3. **정밀 좌표계 변환 & 상세 속성 뷰어**
   - WGS84 위경도(EPSG:4326) ↔ 한국 표준 GRS80 TM 중부원점(EPSG:5186) ↔ UTM-K(EPSG:5179) 상호 자동 변환
   - 원클릭 좌표 복사 및 시설물 단일 JSON 다운로드
   - 관로 단면 수용 다이어그램 및 준공/하자만료 이력 조회

4. **현장 편의 도구 & 확장성**
   - **직선도 스키마틱 뷰어**: 수도권제1순환선 전체 노드(JCT, IC, TG, 지사) 직관적 선형도 제공 및 클릭 시 지도 연동
   - **거리 & 면적 측정기**: 마우스 클릭으로 간이 Ruler 거리(km/m) 및 면적(m²/km²) 실시간 계산
   - **GPS 내 위치 찾기**: 현장 점검 시 모바일/노트북 GPS 기반 실시간 위치 비콘 표시
   - **배경 지도 전환**: 고대비 야간 관제 모드(Dark) / 일반 지도(Standard) / 고해상도 항공 위성 영상(Satellite)
   - **신규 데이터 업로더**: 엑셀(`.xlsx`, `.xls`), CSV, GeoJSON 파일을 드래그 앤 드롭하여 즉시 지도에 오버레이
   - **데이터 내보내기**: 관제 시설물 전체 마스터 데이터 JSON 다운로드

## 🚀 실행 방법

### 방법 1: 즉시 실행 (Python 로컬 서버 - 추천)
바탕화면의 `highway-gis-control` 폴더에서 `run_app.py`를 실행하면 웹 서버가 시작되고 기본 브라우저가 자동으로 열립니다.

```bash
# 터미널에서 실행 시
cd c:\Users\DBCS\Desktop\highway-gis-control
python run_app.py
```
> 브라우저 주소: `http://localhost:8000/index.html`

### 방법 2: 더블 클릭 직접 열기 (독립형 단일 파일)
`highway-gis-control/index.html` 파일을 더블 클릭하여 크롬/엣지 등 브라우저로 바로 실행 가능합니다.

### 방법 3: Node.js (Vite + React) 개발 환경
```bash
cd c:\Users\DBCS\Desktop\highway-gis-control
npm install
npm run dev
```

## 📁 프로젝트 구조

```
highway-gis-control/
├── index.html               # 독립형 인터랙티브 관제 지도 웹 애플리케이션 (React + Leaflet + Tailwind)
├── run_app.py               # 원클릭 로컬 서버 & 브라우저 자동 실행기
├── package.json             # React/Vite 모듈 프로젝트 설정
├── scripts/
│   └── build_data.py        # 바탕화면 엑셀 파일 파싱 및 데이터 추출 파이프라인
└── data/
    ├── master_data.js       # 전역 마스터 데이터 번들 (CORS 없이 직접 로딩)
    ├── master_data.json     # 전체 시설물 통합 JSON
    ├── manholes.json        # 맨홀 120개소 (GPS 좌표 + ITS 장비 융합)
    ├── conduits.json        # 통신관로 120개 구간 (폴리라인 지오메트리 + 관경/수용 규격)
    ├── cables.json          # 광케이블 15개 간선 구간
    ├── poles.json           # 전주 7개소
    ├── cctv_devices.json    # CCTV/AP 449개 통신 장비
    └── straight_map.json    # 수도권제1순환선 직선도 노드
```
